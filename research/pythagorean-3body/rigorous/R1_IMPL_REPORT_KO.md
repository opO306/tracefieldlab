## 1. 쉬운 설명

**하는 일:** 시간을 한 칸(h) 전진하면서 "진짜 상태가 반드시 들어 있는 상자"를 돌려준다.

비유(실제와 구분해서 읽을 것):
- **울타리(사전 상자 B):** 기차가 한 칸 가는 동안 절대 벗어나지 않는 울타리를 먼저 친다. 확인 방법은 "울타리 안에서 낼 수 있는 가장 빠른 속도로 h 시간 내내 달려도 울타리를 못 넘는가"이다. 넘으면 울타리를 넓히거나, 그래도 안 되면 한 칸을 반으로 줄인다.
- **예상 경로(테일러 다항식):** 출발점의 속도·가속도·가가속도… 를 이용해 그린 예상 위치.
- **오차 여유(나머지 항):** 예상 경로에서 버린 부분의 최대 크기를 "울타리 안의 최악의 경우"로 잡아 상자에 더한다.

실제 의미:
- 울타리 = 수학적으로 증명된 "궤적 전체의 포함 상자" B (Picard–Lindelöf 정리 + 구간 포함 검사).
- 예상 경로 = 시작 상자 X0에서 구간으로 계산한 테일러 계수 p차까지의 합.
- 오차 여유 = (p+1)차 계수를 B 위에서 구간으로 계산해 h^(p+1)을 곱한 것(라그랑주 나머지).
- 반올림은 R0의 `dyad.py`가 바깥쪽으로만 하므로 계산 과정에서 상자가 진짜 값을 놓치지 않는다.

증거 수준: **구현됨 + 자체 시험·변이 시험 통과**. 형식 증명 아님, 독립 검증 아님.

## 2. 수학과 재귀식 근거 (코드 머리 주석과 같은 내용)

ODE x′ = f(x), 시작 상자 X0, 보폭 h > 0 (정확한 유리수), 차수 p.

### 2.1 사전 상자 (Picard)
- T(B) := X0 + [0,h]·F(B). F는 f의 구간 확장, [0,h]는 `DI(0, h)`(상한 올림 → [0,h]를 포함).
- **T(B) ⊆ B 이면**, 모든 x0 ∈ X0에 대해 해가 [t0, t0+h]에서 존재·유일하고 B 안에 있다.
  - F(B)가 계산됐다 = 나눗셈의 제수 구간(|r|²)이 0을 포함하지 않았다 → f는 B 위에서 매끄럽다(립시츠).
  - 피카르 연산자 (Px)(t) = x0 + ∫ f(x(s)) ds 의 성분 i는 x0_i + (t−t0)·(f_i의 평균)이고, 평균은 볼록 구간 F_i(B) 안에 있으므로 x0_i + [0,h]·F_i(B) ⊆ B_i 이다. 즉 P는 닫힌 집합 C([t0,t0+h], B)를 자기 자신으로 보내고, 이 집합은 완비이며 P는 가중 노름에서 축약이므로 고정점(진짜 해)이 그 안에 있다.
  - **포함 판정은 끝점의 정확한 유리수 비교이고 경계 일치(=)를 허용한다.** 근거: 위 논증은 닫힌 집합에서 성립하므로 내부(strict) 포함이 필요 없다.
  - 같은 형태의 정리: Nedialkov–Jackson–Corliss (1999), *Appl. Math. Comput.* 105 — **기억에 의한 인용이며 본문을 대조하지 않았다.**
- **다듬기:** 해가 B 안에 있음을 안 뒤에는 같은 적분 논증으로 x(t) ∈ T(B) 이다. 그래서 반환하는 B는 후보가 아니라 T(B)(⊆ 후보)이다.

### 2.2 테일러 상자
- 성분 i마다 실수 함수 x_i(t)에 라그랑주 나머지를 쓴다(벡터 평균값 정리는 쓰지 않는다):
  x_i(t0+h) = Σ_{k=0..p} x_[k],i(x0)·h^k + x_[p+1],i(x(ξ_i))·h^(p+1), ξ_i ∈ (t0, t0+h).
- 자율계이므로 x_[k] = x^(k)/k! 는 그 시각의 상태만의 함수이고, 아래 재귀를 점 상태에 적용한 값과 같다. x(ξ_i) ∈ B 이므로 나머지 ∈ h^(p+1)·[x_[p+1]](B).
- 구현: **X1 = Σ_{k=0..p} [x_[k]](X0)·DI(h^k) + [x_[p+1]](B)·DI(h^(p+1))**. h^k는 정확한 유리수로 구한 뒤 한 번만 바깥 반올림한다.

### 2.3 계수 재귀 (x′ = f(x) 이면 x_[k+1] = f_[k]/(k+1))
- 진동자: x_[k+1] = v_[k]/(k+1), v_[k+1] = −x_[k]/(k+1).
- 곱(코시 곱): (a·b)_[k] = Σ_{j=0..k} a_[j]·b_[k−j]. 제곱은 대칭 쌍을 한 번만 계산해 2배하고, 가운데 항은 `sqr`(음이 아닌 하한)로 계산한다(같은 값, 더 좁음).
- 거듭제곱 w = s^α (s_[0] > 0): w′·s = α·s′·w 의 t^(k−1) 계수를 비교해 유도했다.
  - k·s_[0]·w_[k] = Σ_{i=1..k} ((α+1)·i − k)·s_[i]·w_[k−i]  (k ≥ 1),  w_[0] = s_[0]^α.
  - α = −3/2:  **w_[k] = −(1/(2k·s_[0]))·Σ_{i=1..k} (i + 2k)·s_[i]·w_[k−i]**,  w_[0] = 1/(s_[0]·√s_[0]).
  - 손 검산: s = 1 + t 이면 w_[1] = −3/2, w_[2] = 15/8 (실제 (1+t)^(−3/2) 전개와 일치).
  - Jorba & Zou (2005), *Experimental Math.* 14의 거듭제곱 공식과 같은 꼴 — **기억에 의한 대조, 본문 확인 안 함.** 근거는 위 유도다.
- 중력(N체, G=1): 쌍 (a<b)마다 r = q_b − q_a, s = r_x² + r_y², w = s^(−3/2), u = r·w(코시 곱). a_a += m_b·u, a_b −= m_a·u.
- 케플러: s = x² + y², a = −mu·(x, y)·w.
- s_[0]의 하한 ≤ 0 (충돌 가능 상자) → 내부 예외 `_Singular` → 사전 상자에서는 "이 후보 실패", X0 자체에서면 `TaylorStepError`.
- 질량·mu·정수 계수의 DI는 **호출 시점의 정밀도로** 만든다(`make_*` 시점이 아님, R0 결정 A).

## 3. 사전 상자 알고리즘

```
F0 = F(X0)                                  # 특이점이면 TaylorStepError (h를 줄여도 소용없음)
반복 (h 축소 최대 60회):
    Y = X0 + [0,h]·F0                       # 첫 추정
    최대 10회:
        B = inflate(Y)                      # 양쪽으로 폭/8 + |값|·2^-(prec-4) + 2^-(4·prec)
        F(B)가 특이점이면 중단
        Z = T(B) = X0 + [0,h]·F(B)
        Z ⊆ B (끝점 정확 비교, = 허용) 이면 (Z, h, 누적 검사 횟수) 반환
        Y = Z                               # 엡실론 부풀림 반복
    h = h/2 (정확한 유리수)
실패 → TaylorStepError
```
- 후보를 어떻게 고르든 **정확성은 마지막 포함 검사가 보장**한다. 부풀림 비율·반복 횟수는 효율만 좌우한다.
- `info["apriori_iters"]` = 위 포함 검사의 누적 횟수(h 축소 전후 합계). h 축소 횟수는 log₂(h / h_used)로 알 수 있다.

### 3.1 발견·수정한 결함 (효율, 정확성 위반은 아님)
- **무엇:** 첫 판은 실패 시 `Y = hull(Z, B)`(합집합 상자)를 썼다. 첫 측정(M1)에서 원 궤도 시작 (1,0,0,1)이 h=1/1000에서도 h를 줄였다. 추적해 보니 128비트·h=1/10에서 **h를 2^28배**(h_used ≈ 3.7×10⁻¹⁰) 줄였다.
- **왜:** 이미 통과한 성분(y)까지 매번 1/8씩 커지고, 그 때문에 결합된 성분(vy)에 필요한 폭도 같은 비율로 커져 영영 따라잡지 못했다(반복별 간격 추적으로 확인: vy 상한 초과분이 1e-12 규모로 계속 커짐).
- **왜 못 잡았나:** 자체 시험이 "h_used에서의 정답 포함"만 봤고, 쉬운 경우에 h를 줄이지 않아야 한다는 효율 조건을 검사하지 않았다. 원 궤도 시험은 줄어든 h_used에서도 정답을 포함하므로 통과했다.
- **수정:** `Y = Z` (표준 엡실론 부풀림 반복). 수정 전 실패를 확인한 회귀 시험 `test_no_needless_reduction`을 먼저 추가했다(수정 전: h=1/1000이 1/32000으로 줄어 실패 → 수정 후 통과).
- **수정 후:** 원 궤도 h ≤ 1/10에서 축소 0, 검사 1~2회. 전체 M1 격자에서 검사 횟수 최대 8.
- 폐기된 첫 측정은 `R1_IMPL_MEASURE_v1_superseded*`로 보존했다. 최종 측정은 수정 후 코드로 처음부터 다시 했다.

### 3.2 남은 한계 (설계상)
- 1차 Picard 검사(계획 2절이 정한 형태)는 대략 h·L < 1 (L = f의 립시츠 상수)일 때만 성공한다. 그래서 **케플러 원 궤도 h=1/2는 13개 시작점 모두 h_used = 1/4**(검사 7~8회), 이심 궤도 h=1/2도 1/4로 줄었다. 진동자 h=1/2와 피타고라스 t=0의 h ≤ 1/10은 줄이지 않았다.
- 큰 h를 쓰려면 고차 사전 상자(테일러 꼴 B)가 필요하다. 이번 범위 밖이며, R2 이후 설계자 판단 사항이다.

## 4. 계약 빈칸에 대한 구현 해석 (검사기 작성자와 다를 수 있음)
1. `width_poly`, `width_remainder`, `apriori_width`는 **상태 성분별 목록**(정확한 `Fraction`, 길이 = 상태 차원, 순서 = 상태 순서). 최대값은 `max(...)`로 얻는다.
   - width_poly_i = 다항식 부분 P_i 구간의 폭(반올림 + 입력 폭 전파를 나누지 않음), width_remainder_i = 나머지 구간 R_i의 폭, apriori_width_i = 반환한 B_i의 폭.
   - X1_i = P_i + R_i 이므로 폭(X1_i) ≥ width_poly_i + width_remainder_i (시험으로 확인).
2. `info`의 키는 계약의 6개뿐이다(추가 키 없음).
3. `h`: `int` 또는 `Fraction`. `float`·`bool`·문자열은 `TypeError`, h ≤ 0은 `ValueError`. `order`: 1 이상의 `int`(`bool`·`float`은 `TypeError`, 0 이하는 `ValueError`).
4. `X0`: `DI`의 수열(목록/튜플), 길이가 다르면 `ValueError`, `DI`가 아니면 `TypeError`. 끝점 가수 > `get_prec()`이면 `ValueError`(공개 API `lo_q`/`hi_q`로 판정).
5. 한 걸음을 만들 수 없을 때(X0이 충돌 배치를 포함, 또는 h를 60번 줄여도 사전 상자 실패) → `TaylorStepError`(`RuntimeError`의 하위 클래스).
6. `make_kepler(mu)`, `make_nbody(masses)`는 `int`/`Fraction`을 받는다. `make_nbody`는 천체 1개 이상.
7. 반환 직전에 X1·B 끝점 가수 비트도 검사한다(어기면 `RuntimeError`; dyad 계약상 일어나면 안 됨).

## 7. 한계·미확인
- **독립 검증 없음.** R1-S1~S5는 이 세션이 실행하지 않았다. 자체 시험의 격자가 S1~S3과 같은 모양이어도 같은 사람이 쓴 정답·시험이므로 같은 오해를 공유할 수 있다. 검사기 × 실제 구현 최종 실행은 조율 쪽 몫이다(UNKNOWN).
- **수학적 근거는 사람이 읽는 논증**(2절, 코드 주석)이며 형식 증명이 아니다. 인용 2건(Nedialkov 등 1999, Jorba–Zou 2005)은 기억에 의한 것이고 본문을 확인하지 않았다.
- **mpmath 기준값은 비엄밀**하다(50·70자리 차이를 오차로 추정). 원 궤도·진동자·2체 원 궤도·보존량 시험만 엄밀한 유리수 정답을 쓴다.
- 1차 Picard 사전 상자라 h·L ≈ 1 근처에서 h가 줄어든다(3.2). 근접 조우(L이 큼)에서는 h가 많이 줄 것으로 **추측**한다(미측정, R2 몫).
- `width_poly`는 반올림과 입력 폭 전파를 나누지 않는다(계약대로). 둘을 나누려면 추가 계산이 필요하다.
- 계수를 X0과 B에서 따로 계산한다(최적화 여지, 정확성과 무관).
- `dyad`의 정밀도는 전역 상태다. 다중 스레드에서 다른 정밀도를 쓰면 섞인다(시험 안 함). 지수 범위 제한이 없어 폭이 매우 커지거나 작아지면 정수 크기가 커진다(M2에서 10^34 폭까지는 문제 없음).
- 충돌을 포함하는 상자는 `TaylorStepError`로 거부한다. 충돌에 아주 가까운(포함은 안 하는) 상자에서 h 축소가 얼마나 많아지는지는 미측정.
- 시험 실행 시간이 이 PC 기준 50~80초다. 다른 PC·파이썬 버전의 시간은 미확인.

## 8. 자기반박
- **틀렸다면 어디서 먼저 깨지나:** (a) 포함 판정의 끝점 비교 방향 실수 — 변이 `subset_always_true`는 잡혔지만 "부등호 하나만 뒤집기" 변이는 넣지 않았다. (b) 재귀식의 계수 실수 — s_[1] ≠ 0인 궤도를 추가한 뒤에야 잡혔다. 아직 시험하지 않은 형태: 질량이 매우 다른 N체, 4체 이상, 근접 조우 직전 상태.
- **이번 시험이 통과해도 남는 반례:** 정답·기준값과 구현이 같은 오해를 공유하는 경우(예: 계약의 상태 순서 해석). 독립 검사기가 필요한 이유다.
- **파급효과:** 새 파일만 만들었다. `dyad.py`·계획·봉인·기존 Lab 코드는 바꾸지 않았다(해시 재확인). 검사 세션 파일은 열지 않았다.
- **증거:** 확인한 것 = 위 자체 시험 23/23, 변이 19/19, 측정값(이 PC 1회). 추측 = 근접 조우에서의 h 축소, 다른 환경의 속도.
