## 0. 쉬운 설명 (비유와 실제 의미를 구분)

**비유.** R4가 남긴 것은 "그 시각 세 별의 위치·속도는 반드시 이 상자 안에 있다"고 보장하는 사진 302장이다(151개 시각 × 2장). 이번 일은 사진 한 장 한 장을 보고, 사진 속 **어느 점을 골라도** 세 가지 질문에 "예"가 나오는지 따져 보는 것이다.
1. 쌍성(4·5)은 충분히 붙어 있는가? (C1)
2. 별 3은 쌍성에서 충분히 멀리 있는가? (C2)
3. 별 3은 바깥으로, 남은 "언덕"을 넘을 만큼 빠르게 나가고 있는가? (C3)

세 질문이 모두 "예"인 사진이 한 장이라도 있으면, 요시다 정리(수정판 ★)에 따라 그 순간부터 별 3은 영원히 돌아오지 않는다는 결론이 나온다. 세 질문 중 하나라도 "사진 속 일부 점에서 아닐 수 있다"면 그 사진은 쓰지 않는다(NOT_CERTIFIED). 이것은 "조건이 거짓"이라는 뜻이 아니라 "이 사진만으로는 보장하지 못한다"는 뜻이다.

**실제 의미.** 위 세 질문은 각각 r < d₁, ρ > λd₁, ρ̇ > √(2M·W(ρ, d₁))이다(2절). 판정은 서로 전혀 다른 방식으로 만든 판정기 두 개로 따로 했다. 하나는 정확한 분수와 정수 제곱근만 쓰고, 다른 하나는 mpmath 구간 산술(256비트)을 쓴다.

**결과 한 줄.** 두 판정기가 **같은 결론**을 냈다. t = 59.73(k = 5973)부터 t = 61.00(k = 6100)까지 **128개 시각 전부, 시각마다 두 장 모두(256장) PASS**이고, t ≤ 59.72(k ≤ 5972)의 46장은 하나도 PASS가 아니다. 이는 비엄밀 기준 궤적이 예측한 첫 성립 시각 59.7223과 어긋남이 없다.

## 2. 무엇을 어떻게 판정했나

### 2.1 판정할 식 (YOSHIDA_REDERIVATION_KO.md 3절의 (★), 계획 2절)
- 상태 12성분 순서: x₀,y₀,x₁,y₁,x₂,y₂,vx₀,vy₀,vx₁,vy₁,vx₂,vy₂. 질량 m₀=3(탈출체), m₁=4, m₂=5. G=1.
- r̄ = q₂ − q₁, r = |r̄|. G = (m₁q₁+m₂q₂)/(m₁+m₂), ρ̄ = q₀ − G, ρ = |ρ̄|, ρ̇ = (ρ̄·ρ̄̇)/ρ.
- λ = 5/9, ν = 4/9, M = 12, K = 769/60, **d₁ = 1200/769**, W(ρ, d) = λ/(ρ+νd) + ν/(ρ−λd).
- C1: r < d₁ · C2: ρ > λd₁ · C3: ρ̇ > √(2M·W(ρ, d₁)). 상자 안 **모든 점**에서 엄격히 성립해야 PASS.

### 2.2 두 판정기 (코드 공유 없음)
| | `y1_exact.py` | `y1_mpiv.py` |
|---|---|---|
| 수 체계 | Fraction (정확한 유리수). 구간 = (하한, 상한) 쌍 | mpmath `iv` 구간 산술, 256비트 (계획 요구 ≥ 200) |
| 제곱근 | `math.isqrt`로 유리수 상·하한 (정밀도 2⁻²⁰⁰), 하한은 아래로·상한은 위로 | `iv.sqrt` (바깥 반올림) |
| C1, C2 판정 | 제곱으로 판정: r² 상한 < d₁², ρ² 하한 > (λd₁)² (제곱근 없이 정확히) | 여유 구간 (d₁−r), (ρ−λd₁)의 하한 > 0 |
| C3 판정 | ρ̇ 하한 > 0 이고 ρ̇ 하한² > 2M·W(ρ 하한) (W는 ρ에 대해 감소하는 성질 이용) | 여유 구간 (ρ̇ − √(2MW))를 구간 산술로 직접 계산, 하한 > 0 |
| 부동소수점 | 판정에 한 번도 쓰지 않음 | `mpmath.libmp` 끝점 직접 비교(구간 `<`는 겹치면 None을 돌려줘 쓰지 않음) |

- 상자 하나의 각 조건 상태: **PASS**(상자 전체에서 참) / **REFUTED**(상자 전체에서 거짓) / **UNDECIDED**(걸침) / **UNDEFINED**(C3만: C2가 보장되지 않아 W가 의미 없음). 상자 판정은 셋 다 PASS일 때만 PASS, 아니면 NOT_CERTIFIED. REFUTED/UNDECIDED 구분은 계획에 없던 **측정용 추가 정보**이며 판정 규칙에는 영향이 없다.
- 구간 안의 각 변수가 식에 한 번씩만 나오는 부분(r̄, ρ̄, ρ̄̇, 그 내적)은 구간 범위가 정확하다. ρ̇ = N/ρ에서 N과 ρ가 같은 변수를 공유해 생기는 구간 과대평가는 PASS를 덜 주는 안전한 방향의 오차다. 좁은 상자(폭 ≤ 3.3×10⁻⁹)에서는 무시할 만하고, 넓은 상자(폭 ≤ 6.3×10⁻²)에서는 여유 하한을 낮추지만(6절 표의 0.014~0.032) 두 종류 모두 PASS라서 결론은 바뀌지 않는다. [확인]

### 2.3 해석을 내가 정한 곳 (계획이 말하지 않은 부분, 기록)
- **J1. C2가 보장되지 않으면 C3는 평가하지 않는다(UNDEFINED, PASS 아님).** W(ρ, d₁)는 ρ > λd₁에서만 의미가 있다. 계획 3절 (d)의 "C2만 깨는 상태에서 C3는 통과해야 한다"는 문자 그대로는 만들 수 없다(ρ ≤ λd₁이면 C3 식 자체가 정의되지 않음). 그래서 (d)의 C2 시험은 "C1은 PASS, C2는 PASS 아님, C3는 UNDEFINED"로 기대값을 정했다.
- **J2. 등식 경계 상태**(r = d₁ 정확히, ρ = λd₁ 정확히)는 정확 분수 판정기는 REFUTED, 구간 판정기는 UNDECIDED가 나올 수 있다. 시험 기대값은 "둘 다 PASS 아님"으로 했다(둘 다 그렇게 나옴).
- **J3. 같은 k의 두 상자는 각각 따로 판정**했다. "PASS인 k"는 그 k의 두 상자 중 적어도 하나가 두 판정기에서 PASS일 때로 세었는데, 실제로는 모든 k에서 두 장 모두 PASS이다.
- **J4. 기준 궤적 여유값의 정의.** `analyze_taylor_output.txt`의 "margin(vel)"은 ρ̇ − √(2M·W(ρ, d₁))임을 수치로 확인했다(반례 (a2)에서 판정기 값과 1.1×10⁻¹⁵ 일치, 표 12행에서 최대 5.7×10⁻⁵ 일치).
- **J5. 계획 4절의 "기준 궤적 여유 −0.012 (t = 59.72)"** 라는 숫자는 재유도 보고서나 출력 파일에서 찾지 못했다. 보고서의 t = 59.73 여유 0.0374와 첫 성립 시각 59.7223에서 보외하면 대략 −0.011이다. 이번 R4 좁은 상자의 k = 5972 값은 −0.012143이어서 계획의 숫자와 같다(6절).
