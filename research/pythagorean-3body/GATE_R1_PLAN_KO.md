# Gate R1 계획 — 엄밀 테일러 한 걸음 (2026-10-11)

> 상태: 계획(실행 전 봉인). 봉인 해시는 `GATE_R1_SEAL.json`. 실행 뒤 수정 금지.

## 0. 쉬운 설명
- 시간을 **한 칸** 전진하면서 "진짜 상태가 반드시 들어 있는 상자"를 만드는 부품을 만든다.
- 두 가지 오차를 모두 막는다.
  - 반올림: R0의 구간 산술이 막는다.
  - 근사 오차: 테일러 전개에서 버린 나머지 항의 **최대 크기**를 엄밀히 구해 상자에 더한다.
- 정답을 아는 문제(진동자, 원 궤도)와, 아주 높은 정밀도로 따로 계산한 삼체 문제 한 칸으로 시험한다.
- 잡초 관리(개정 2)의 기초로, 상자 폭이 **어디서 왔는지(원인별 몫)**를 기록한다.

## 1. 목표와 비목표

    - 구간 테일러 계수(자동 미분 재귀)
    - 나머지 항 상한
    - 원인별 폭 기록

## 2. 수학 (구현과 검사가 공유하는 근거)
- ODE x′ = f(x). 시작 상자 X₀, 보폭 h > 0(정확한 유리수).
- **사전 상자 B:** 후보 B에 대해 X₀ + [0,h]·F(B) ⊆ B (F는 f의 구간 확장)가 성립하면, [t₀, t₀+h] 동안의 진짜 해 전체가 B 안에 있다(Picard–Lindelöf + 구간 포함). 성립하지 않으면 B를 넓히거나 h를 줄인다(h를 줄였으면 사용한 h를 반환).
- **테일러 상자:** 차수 p. 계수 x_[k] (k=0..p)는 X₀에서 구간으로 계산한다. 나머지는 h^{p+1}·x_[p+1](B)이며, (p+1)차 계수를 사전 상자 B 위에서 구간으로 계산한 것이다.
  - X₁ = Σ_{k=0..p} x_[k](X₀)·h^k + h^{p+1}·x_[p+1](B)
- 테일러 계수는 `x_[k] = (1/k!) dᵏx/dtᵏ`이고, 표준 재귀(곱, 거듭제곱 r^{−3})로 구한다.

## 3. API 계약 (검사기는 이것만 보고 만든다)
- `make_harmonic()` : 상태 [x, v], x′=v, v′=−x.
- `make_kepler(mu: Fraction)` : 평면, 상태 [x, y, vx, vy], 가속도 −mu·r/|r|³.
- `make_nbody(masses: list[Fraction])` : 평면 N체, G=1. 상태 [x₁,y₁,…,x_N,y_N, vx₁,vy₁,…,vx_N,vy_N].
- `taylor_step(system, X0: list[DI], h: Fraction, order: int) -> (X1: list[DI], B: list[DI], info: dict)`
  - 호출 전 `dyad.set_prec(p)`를 한 번 정한다(R0 결정 A). 함수는 입력 끝점 가수가 현재 정밀도 이하인지 확인하고, 아니면 `ValueError`.
  - `info` 키
    - `h_used`(Fraction): 사전 상자가 실패해 줄였을 수 있음. X1은 t₀+h_used 시각의 상자다.
    - `order`
    - `apriori_iters`
    - `width_poly`: 다항식 부분의 폭(반올림 + 입력 폭 전파)
    - `width_remainder`: 나머지 항의 폭
    - `apriori_width`
  - 보장: 진짜 해 x(t₀+h_used)가 X1 안에 있고, [t₀, t₀+h_used]의 진짜 해가 B 안에 있다(X0 안의 모든 시작점에 대해).

## 5. 독립성
- 구현 세션은 `taylor_step.py`와 자체 시험만 만든다. 검사기 파일은 읽지 않는다.
- 검사 세션은 `taylor_step.py`를 열지 않고, 이 계획의 2·3절만 근거로 `check_r1.py`와 독립 기준값 계산을 만든다. `dyad.py`는 import해서 DI를 만드는 데만 쓴다(API만 사용).
- 최종 실행(검사기 × 실제 구현)은 조율 쪽에서 한다.
