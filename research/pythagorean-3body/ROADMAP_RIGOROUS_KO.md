# 자체 오차 상자 적분기 로드맵 v0 (2026-10-11)

## 설계자 결정 (2026-10-11)
- 엄밀한 오차 상자 적분기를 **우리가 처음부터 만든다.** CAPD 등 기존 엄밀 적분 라이브러리는 쓰지 않는다.
- 목표는 돈이 아니라 **새로운 발견**이다. "세계에 점 하나"를 찍는 것.

## 최종 목표 (가설)
피타고라스 삼체 문제의 결말 — **m2·m3 쌍성 + m1 영구 탈출** — 의 **컴퓨터 보조 증명**.
1. t=0부터 시각 T까지 진짜 궤적을 감싸는 **오차 상자**를 엄밀하게 계산한다.
2. 시각 T에서 **해석적 영구 탈출 판정 기준**(Alexeev 1961, Yoshida 계열)을 오차 상자 전체가 만족함을 보인다.
3. 계산 결과를 **증명서(certificate)** 파일로 남긴다. **실행기와 다른 세션이 만든 검증기**가 이 증명서를 독립적으로 다시 확인한다.

## "점 하나"가 되려면 (정직한 조건)
- 방법 부품(구간 산술, 테일러 적분, Lohner식 상자 회전, 정칙화)은 **이미 알려진 기술**이다. 새로운 것은 방법이 아니라 **결과**여야 한다.
- 그 결과는 "피타고라스 문제 결말의 엄밀 증명"이다. 이것이 새것인지는 **아직 모른다.** 검색 3회에서는 찾지 못했다. → R0와 함께 **깊은 선행 연구 조사**를 한다.
- 이미 누가 했다면 목표를 다시 정한다(설계자 결정). 후보:
  - 그 결과를 독립 구현으로 재확인
  - 더 긴 시간, 근처 초기조건 영역까지 넓히기
  - 더 쉽게 검증 가능한 증명서 형식

## 단계 (각 단계는 계획 봉인 → 실행 → 독립 검증)

| 단계 | 내용 | 통과 조건 요지 |
|---|---|---|
| **R0** | 자체 **이진 분수 구간 산술**(정수 가수 × 2^지수, 바깥쪽 반올림)과, 정확한 분수(Fraction)로 만든 독립 검사 | 포함 위반 0, 경계 사례 전부 |
| R1 | 엄밀 테일러 적분 1 step(사전 상자 + 나머지 항 상한). 정답을 아는 문제(조화진동자, 2체 케플러)로 시험 | 진짜 해가 상자 안에 있음, 위반 0 |
| R2 | 피타고라스 문제를 그대로 적분해 **어디서 상자가 터지는지** 측정 | 측정 보고 |
| R3 | 상자 부풀음 억제(구간 나누기, Lohner식 회전 — 직접 구현) | R2보다 멀리 가는지 |
| R4 | 근접 조우 처리(필요하면 Levi-Civita 정칙화 — 직접 구현) | t₁₀(15.83) 통과 |
| R5 | t≈70까지 + 탈출 판정 기준의 엄밀 검사 + 증명서 + 독립 검증기 | 검증기 PASS |

## 위험 (미리 공개)
- **R2–R5 성공 여부는 UNKNOWN이다.** Gate P3B-0의 측정 결과는 다음과 같다.
  - t=70에서 오차가 약 4×10⁹배로 커졌다.
  - 가장 비싼 구간은 끝부분(쌍성 근점 통과)이었다.
  - 상자 방식은 여기에 군더더기 부풀음까지 더해진다.
- 파이썬 속도 한계가 있을 수 있다. 필요하면 나중에 구현 언어를 바꾸는 것을 검토한다(설계자 결정).
- 사용할 탈출 판정 기준의 정확한 수학적 진술을 아직 읽지 않았다. → 조사 대상.
