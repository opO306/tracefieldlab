## 2. 판정할 조건 (★) — `YOSHIDA_REDERIVATION_KO.md` §3
기호: λ = m₂/(m₁+m₂) = 5/9, ν = m₁/(m₁+m₂) = 4/9, M = 12, K = 769/60, d₁ = m₁m₂/K = 1200/769.
- r̄ = q₂ − q₁ (쌍성 4→5), r = |r̄|
- G = (m₁q₁ + m₂q₂)/(m₁+m₂), ρ̄ = q₀ − G, ρ = |ρ̄|, ρ̇ = (ρ̄ · ρ̄̇)/ρ
- W(ρ, d) = λ/(ρ + νd) + ν/(ρ − λd)

상자 하나가 **통과(PASS)**하려면 상자 안 모든 점에서 엄격히:
- C1: r < d₁
- C2: ρ > λ·d₁
- C3: ρ̇ > √(2M·W(ρ, d₁))  (구현은 ρ̇ > 0을 먼저 보이고 ρ̇² > 2M·W로 판정해도 된다)

판정은 구간의 **바깥쪽 끝**으로 한다. 예를 들어 C1은 r²의 상한 < d₁²이다. 하나라도 보장이 안 되면 그 상자는 **판정 불가(NOT_CERTIFIED)**다. 이것은 "조건이 거짓"이라는 뜻이 아니다.

## 3. 만들 것 (Y1 판정 세션, 조율 쪽이 아님)
1. `yoshida_check/y1_exact.py`: 표준 라이브러리만(Fraction, math.isqrt). 구간 = (하한, 상한) Fraction 쌍. 제곱근은 유리수 상·하한으로 바깥쪽에 감싼다.
2. `yoshida_check/y1_mpiv.py`: mpmath `iv`(구간) 컨텍스트, 정밀도 ≥ 200비트. y1_exact와 코드를 공유하지 않는다.
3. 자기시험 `yoshida_check/y1_selftest.py` (두 판정기 모두에 대해):
   - (a) `YOSHIDA_REDERIVATION_KO.md`의 원문 Corollary 반례 상태(t≈17.118, r=3.351)를 폭 0 상자로 → C1 실패여야 함.
   - (b) 경계를 걸친 상자(예: 한 성분을 ±0.05 넓혀 C3 여유를 넘게) → NOT_CERTIFIED여야 함.
   - (c) 손으로 만든 명백한 탈출 상태(ρ 크고 ρ̇ 크고 r 작음) → PASS여야 함.
   - (d) 조건 하나씩만 깨는 상태 3종 → 해당 조건만 실패해야 함.
   - (e) 상수(λ, ν, d₁)를 일부러 틀린 가짜 판정기 ≥ 3종이 (a)~(d) 중 적어도 하나에서 다른 결과를 내야 함(검사력 확인).
4. 보고서 `yoshida_check/Y1_RESULT_KO.md`.

## 4. 판정 규칙 (실행 전 고정)
- **Y1 통과** = 두 판정기 모두에서 PASS인 상자가 **하나 이상** 있고, 자기시험이 모두 통과.
- 두 판정기의 결론이 한 상자라도 다르면(한쪽 PASS·다른 쪽 NOT_CERTIFIED) → 그 상자는 판정에 쓰지 않고 원인을 기록한다. 그래도 둘 다 PASS인 상자가 있으면 통과다.
- **일관성 점검(측정, 판정 아님):** 비엄밀 기준 궤적으로는 조건이 t ≈ 59.7223에 처음 성립한다. 그래서 k ≤ 5972인 상자는 C3가 실패해야 정상이다(기준 궤적 여유 −0.012, t=59.72). 만약 k ≤ 5972에서 PASS가 나오면 계산 오류를 의심하고 원인을 찾을 때까지 Y1 통과를 보류한다.
- 보고: k별 C1·C2·C3의 보장된 여유(하한), 처음 PASS인 k, PASS인 k의 개수.
