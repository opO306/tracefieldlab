# Gate R3c 계획 — 기울인 상자(Lohner–QR) 엄밀 적분, t∈[0,20] 시험 (2026-10-11)

> 상태: 계획(실행 전 봉인). 봉인 해시는 `GATE_R3C_SEAL.json`. 실행 뒤 수정 금지.

## 0. 쉬운 설명
- 반듯한 그릇 대신 **반죽 방향을 따라 기우는 그릇**을 만든다.
  - 그릇 = 중심점 하나 + 기울어진 축 12개(행렬) + 축마다의 폭(이름표 12개)
  - 매 걸음 반죽이 늘어나고 회전하는 방향을 계산해서 그릇 축을 같이 돌린다.
- 줄어드는 방향의 이득을 버리지 않기 때문에, R1·R2에서 본 군더더기 부풀음이 크게 줄어들 것으로 기대한다(추정, 이번에 측정).
- 먼저 t=0–20(근접 조우 17회 포함)만 시험한다. 그 결과로 t≈60까지 갈 수 있을지 판정한다.
- 이 방법의 원리(Lohner 1987, QR 기준 바꾸기)는 알려진 기법이다. 우리 Lab V2(오차 이름표 + QR)의 생각을 테일러 나머지 항까지 포함해 **직접 다시 구현**한다. 외부 엄밀 적분 라이브러리는 쓰지 않는다.

## 3. 수학 (구현·검사 공유 근거)
상태 집합 표현: X_k = { c_k + B_k·r : r ∈ R_k } ∪ (포함 여유).
- c_k: 점(이진 분수 12개)
- B_k: 12×12 점 행렬(이진 분수)
- R_k: 구간 벡터(이름표 폭)

한 걸음 (보폭 h):
1. 사전 상자: R1과 같은 Picard 검사를 X_k의 구간 외접 상자에 적용해 [t_k, t_k+h] 경로 상자 P를 얻는다.
2. 중심 이동: 점 c_k에서 차수 p 테일러 다항식 T(c_k)를 구간으로 계산하고, 나머지 Z = h^{p+1}·x_[p+1](P)를 더한다.
3. 기울기 행렬: 테일러 다항식의 상태에 대한 미분 J를 구간으로 계산한다(테일러 계수 재귀에 12방향 전진 자동미분). 나머지의 미분 몫은 P 위의 변분 계수로 감싼다. 둘을 합쳐 흐름 사상의 미분을 감싸는 구간 행렬 [J]를 얻는다.
   - 엄밀한 형태: φ(x) − φ(c) ∈ [J]·(x − c) (평균값 정리)
   - [J]는 X_k 전체에서 φ의 미분을 포함하도록 계산한다.
4. 새 중심: c_{k+1} = mid(T(c_k) + Z)(이진 분수로 반올림한 점).
5. 새 틀
   - mid([J])·B_k를 열 노름 순으로 피벗한 QR로 분해한다(근사, 비엄밀 허용).
   - B_{k+1} = Q(이진 분수로 반올림한 점 행렬).
   - B_{k+1}의 역행렬은 **정확한 유리수 계산(Fraction)**으로 구한 뒤 바깥쪽 구간으로 감싼다. 이 단계가 엄밀성의 핵심이다.
6. 새 이름표
   - R_{k+1} = [B_{k+1}⁻¹]·([J]·B_k)·R_k + [B_{k+1}⁻¹]·(T(c_k) + Z − c_{k+1})
   - 모두 바깥 반올림 구간 연산이다.
7. 정밀도는 실행 중 하나로 고정한다(R0 결정 A). 걸음마다 가수 비트를 확인한다.

**보장**: 진짜 해 x(t_{k+1})는 c_{k+1} + B_{k+1}·R_{k+1} 집합 안에 있다. 외접 상자로 바꿔도 포함은 유지된다.

## 4. 보폭 규칙 (R2의 누적 문제 수정, 실행 전 고정)
- 차수 p = 20.
- 걸음마다 나머지 허용치를 **현재 폭에 비례시키지 않고 절대값으로 고정**한다: tol = 2^(−prec+16) × max(1, |c_k|∞).
- 시도 보폭: h = 0.9 × (tol / max|x_[p](c_k)|)^(1/p)를 2의 거듭제곱 분수로 내림한다. 상한 1/8.
- 걸음 뒤 나머지 폭 > tol이면 h를 절반으로 해서 다시 한다(최대 20회).
- 정밀도는 128비트와 256비트, 두 실행이다.

## 6. 판정 규칙 (실행 전 고정, 다음 단계 결정용)
- [10,20] 구간의 평균 성장률로 t=60의 log10 폭을 선형 외삽한다(외삽은 추정임을 명시).
- 외삽 폭 ≤ 10⁻⁶이고 R3-S1–S4 위반 0이면 → **R3c를 주 경로로 확정**하고, 다음 Gate에서 t=60까지 연장한다(설계자 승인 후).
- 외삽 폭 > 10⁻⁶이면 → 원인 분석(성장률이 큰 구간)과 함께 다음 중 하나를 설계자에게 올린다.
  - R3e(근접 조우 정칙화)
  - R3a·R3b(법칙 깎기)
  - R3H(헬기) 승격
- 엄밀성 위반이 하나라도 있으면 → 측정 결과와 무관하게 중단하고 원인을 분석한다.

## 7. 독립성
- 구현 세션: `lohner_step.py`, 실행·분석 스크립트, 자체 시험만 만든다. 검사기 파일은 읽지 않는다.
- 검사 세션: 이 계획 3절 수학과 아래 API만 보고 `check_r3c.py`, 가짜·참조 구현을 만든다. `lohner_step.py`는 읽지 않는다.
- API 계약
  - `lohner_init(system, x0: list[Fraction]) -> state`
  - `lohner_step(system, state, h: Fraction, order: int) -> (state_new, info)`
  - `state.c`(list[Fraction]), `state.B`(list[list[Fraction]]), `state.R`(list[DI]), `state.t`(Fraction)
  - `enclosure_box(state) -> list[DI]`
  - `info`: `h_used`, `width_remainder`, `apriori_iters`, `injected_width`
  - system은 R1의 `make_harmonic` / `make_kepler` / `make_nbody`를 그대로 쓴다.
  - 사전 상자 실패로 h를 줄이면 `h_used`에 반영한다.
- 최종 실행(검사기 × 실제 구현)과 결과 판정은 조율 쪽에서 한다.

## 8. 실패 대응
- 위반이나 오류가 나면 바로 고치지 않는다. 최소 반례와 원인, "왜 자체 시험이 못 잡았나"를 기록한다.
- 규칙·기준은 바꾸지 않는다.
- QR 역행렬 단계에서 조건수가 나빠 폭이 폭증하면 그 걸음과 조건수를 기록하고 측정 결과로 보고한다(실패가 아니다).
