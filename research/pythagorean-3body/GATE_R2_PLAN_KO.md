# Gate R2 계획 — 반듯한 상자로 피타고라스 문제 이어 돌리기: 기준선 측정 (2026-10-11)

> 상태: 계획(실행 전 봉인). 봉인 해시는 `GATE_R2_SEAL.json`. 실행 뒤 수정 금지.

## 0. 쉬운 설명
- R1의 "한 칸 전진 계산기"를 그대로 이어 붙여 t=0부터 계속 돌린다.
- 반듯한 상자가 **언제, 어디서, 무엇 때문에** 터지는지 잰다.
- 아무 손질도 하지 않는 "잡초 방치" 상태의 기준선이다. 터지는 것이 예상 결과이고, 실패가 아니다.
- 정밀도 두 가지(128비트, 256비트)를 비교해 "인력(자릿수) 추가"가 얼마나 시간을 벌어 주는지도 잰다.

## 1. 목표와 비목표
- 목표
  - `rigorous/r2_run.py`(이어 돌리기 + 기록), `rigorous/r2_analyze.py`(분석)
  - 결과 `rigorous/r2_results/`, `rigorous/R2_RESULT_KO.md`
- 비목표: 상자 손질(R3), 정칙화(R4), 탈출 판정(R5). `dyad.py`·`taylor_step.py` 수정 금지(봉인 해시로 고정).

## 2. 고정 입력
- `dyad.py` sha256 `4d49cf8f…abaab`, `taylor_step.py` sha256 `0183f0f8…be01c31`(전체 해시는 봉인 파일)
- 초기상태: 질량 (3,4,5), 위치 (1,3), (−2,−1), (1,−1), 속도 0. 점 구간(정확값).
- 기준 궤적(독립 실행기 산출물): `results/ref_B_grid.json`(60자리, 0.01 간격, t=0–70). 자체 오차 ≲ 10⁻²⁰ 수준(Gate P3B-0 결과: A·B 일치 + 독립 방식 일치).

## 3. 이어 돌리기 규칙 (실행 전 고정)
- 차수 p=24.
- 정밀도 설정 2개: 128비트, 256비트(각각 별도 실행, 결정 A).
- 보폭 규칙(결과를 보기 전에 고정)
  - 시도 보폭 h는 이전 걸음의 h_used × 2(상한 1/16), 첫 걸음은 1/64.
  - 걸음 뒤 `width_remainder > max(width_poly, 2^(−prec+20))`이면 그 걸음을 버리고 h를 절반으로 다시 한다.
  - h는 항상 2의 거듭제곱 분수다.
- 걸음마다 기록: t(정확한 유리수), h_used, 상태 12성분의 최대 폭, width_poly, width_remainder, apriori_iters, 경과 시간.
- 중단 조건(먼저 오는 것)
  - (a) 상태 최대 폭 > 1(상자가 배치 크기 수준 = 터짐)
  - (b) h_used < 2⁻⁶⁰
  - (c) t ≥ 70
  - (d) 실행 wall 60분

## 4. 측정 항목
| ID | 항목 |
|---|---|
| R2-M1 | 터진 시각 t_explode와 중단 사유(정밀도별) |
| R2-M2 | 상자 폭 성장 곡선(log10 최대 폭 대 t), 근접 조우 시각(Gate P3B-0 목록)과 겹쳐 그리기 |
| R2-M3 | 구간별 성장률(시간 1당 log10 증가)과 원인 몫(poly 대 remainder) |
| R2-M4 | 정밀도 효과: 256비트가 128비트보다 몇 시간 단위 더 갔는가 |
| R2-M5 | 걸음 수·h 분포·실행 시간 |

## 5. 정확성 점검 (합격 기준)
| ID | 기준 | 판정 |
|---|---|---|
| R2-S1 | 기준 궤적 격자점(0.01 간격)에서, 상자 폭이 10⁻¹⁵보다 큰 시각에는 기준 상태가 상자 안에 있음. 기준값 자체 오차를 감안해, 기준 궤적은 상자 폭이 10⁻¹⁵ 이하인 시각에는 판정하지 않음(UNDECIDED로 기록) | 위반 0 → PASS |
| R2-S2 | 격자점이 걸음 사이에 있으면, 해당 걸음의 경로 상자 B로 판정 | 위반 0 |

- 걸음 끝 시각이 격자점과 다르면 경로 상자 B를 쓴다.
- 기준 궤적의 오차가 상자보다 크면 판정하지 않는다(UNDECIDED).
- 비교는 Fraction으로 엄밀하게 한다.

## 6. 실패 대응
- S1 위반이 나오면 즉시 중단한다. 최소 반례(시각, 성분, 상자, 기준값)를 기록하고 원인을 분리한다(구현 결함 / 기준 궤적 오차 / 비교 규칙). 고치지 않고 보고한다.
- 규칙·기준은 바꾸지 않는다.

## 7. 자원
- 이 PC, 시스템 Python 3.12(+ 분석용 mpmath).
- 128·256비트 실행을 동시에(2 프로세스) 돌린다. 각 wall 60분 상한.
- 네트워크·설치·서버·커밋 없음.

## 8. 증거 수준
- 측정 + 포함 점검(시험 격자). 증명 아님.
- "터진 시각"은 **이 보폭 규칙과 반듯한 상자에서의 값**이다. 방법 일반의 한계가 아니다.
