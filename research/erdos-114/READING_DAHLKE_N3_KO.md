## 5. 판정
- **현재 확인 범위 안에서 오류를 찾지 못함.** 외부 의존은 EH99 Lemma 5 하나.
- 이것은 "증명이 맞다"는 인증이 아님: 검토자는 AI 한 명, 수치는 비엄밀. 사람 전문가 검토 없음.
- 우리 계획에 주는 의미: n = 3은 Dahlke 원고로 이미 (미검토) 해결 주장이 있고, 우리 확인도 그 방향 → **n = 3 독립 확인 단계는 사실상 끝**. 남는 기여 후보: (1) 이 원고의 상수들을 바깥 반올림 구간 연산으로 확인하는 작은 검사기(저비용, 검토자 부담 감소), (2) n = 4.
- n = 3 방법이 n = 4로 그대로 가지 않는 이유(추론): n = 3 정규형이 척도 조정된 체비셰프 T₃가 되는 것은 임계값이 2개뿐이라 1변수로 줄기 때문. n = 4는 임계값 3개 → 2변수 + 가지, T₄ 구조는 특수한 경우에만.
