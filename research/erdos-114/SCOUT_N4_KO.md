# n = 4 지형 정찰 (비엄밀) — 2026-10-13

**증명 아님.** 배정밀도 수치 적분으로 지형을 본 것. 엄밀 증명 설계의 비용·난점 판단용.

## 1. 무엇을 계산했나
- 대상: 임계값 3개가 모두 단위원 위인 centered monic quartic (EH99 Lemma 5에 의해 최댓값 비교는 이 부류로 충분 — READING_EH99_KO.md 2절).
- 매개화: Lee 노트(github.com/jaeseostudy/quartic-polynomial-lemniscates, 커밋 65db9e32aa) 식 (2.x)의 gap 좌표 (a, b), a, b > 0, a + b < 2π. 각 점에서 스칼라 4차식 P_X(A) = 0의 근으로 다항식 복원 → 임계값이 실제로 일치하는 것만 남김(가짜 근 제거). 대칭 s → −s, t → −t는 같은 곡선.
- 길이: L = ∫₀^{2π} Σ_{p(z)=e^{iθ}} 1/|p′(z)| dθ, 임계값 각도에서 자르고 각 반쪽을 θ = 끝점 ± u²로 치환, 가우스–르장드르 160점. 근은 동반행렬 고윳값(numpy).
- 코드: 세션 스크래치 `quartic/scout.py`, `corner.py`, `landscape.py`, `symcheck.py`, `validate.py` (저장소에 넣지 않음).

## 2. 결과
- 격자 N = 96 (gap 간격 2π/96), 점 × 가지 = 17,859개. 거의 모든 점에서 가지 4개(a = b = 2π/3 한 점만 3개).
- **최댓값은 세 꼭짓점 근처뿐**(세 꼭짓점은 대칭상 같은 점 = 임계값 3개가 한 점에 모임 = z⁴ − 1). 격자 최댓값 9.8856 (L* = 11.0700의 0.893), 최근접 격자점.
- max-over-sheets 함수의 격자 국소 최대: 세 꼭짓점 이웃 점뿐. 안쪽 봉우리 없음.

## 3. 실패와 수정 (기록)
- 처음 치환 θ = 끝점 ± u⁶ → 노드가 임계값에 10⁻¹⁵까지 붙어 배정밀도에서 겹근 구분 불가 → |p′| ≈ 0 오판, S = 4×10¹⁴ → 한 구간 1.07 과대(가짜 "안쪽 봉우리" 3개 생김).
- **발견 경로: 대칭 검사.** 같은 곡선이어야 할 6개 대칭 위치의 값이 다름(9.709 vs 8.638) → 구간별 비교로 원인 특정 → u²로 낮춤 → 대칭 일치, 가짜 봉우리 사라짐.
- 교훈(MendozaLab 결함 1·2와 같은 계열): 특이 적분의 부동소수 값은 함정이 많음. 엄밀 단계에서는 임계값 근처를 해석적 전개(Lee 식 Sasymp: S = C|η|^{−1/2} + O(1))나 구간 연산으로 따로 처리해야 함. 대칭 불일치는 값싼 독립 경보로 계속 쓸 것.

## 5. 엄밀 증명 설계에 주는 의미 (추론)
1. 지도 안쪽은 여유가 큼(결손 ≥ 약 1.2, 꼭짓점·가장자리 근처 제외) → 상자 탐색으로 닫기 쉬울 것으로 보임.
2. **어려운 곳은 꼭짓점 근처와 가장자리.** 꼭짓점에서 결손이 ε^{1/4}로 0에 가므로 상자 탐색만으로는 못 닫음 → 꼭짓점 이웃(명시적 반지름)에서 L ≤ L* − c·ε^{1/4} 같은 해석적 국소 부등식 필요(Fryntov–Nazarov 국소 최대성의 정량판, 또는 n = 3 Dahlke 방식의 확장).
3. 가장자리(두 임계값 충돌)에서는 밀도 특이성이 |η|^{−2/3}로 바뀜 → 길이 상한 계산에서 따로 다룰 것. Lee가 "열림"이라 한 이중 임계 경계 비교와 같은 곳.
4. 미확인: 꼭짓점 근처를 해석적으로 덮을 반지름과, 상자 탐색이 그 반지름까지 내려갈 수 있는지(두 영역이 겹쳐야 증명이 닫힘).
