## 2. 핵심: Lemma 5의 정확한 의미

- 원문: "극대 다항식 중 **어떤 하나는** 모든 임계점이 E(p) 위에 있다" = 모든 임계값이 단위원 T 위 (p.7: "all critical values belong to T. This is equivalent to the property that all critical points of p* belong to E(p*)").
- 증명 방식: 극대 p의 임계값 하나를 T 밖에서 조금 움직이면(준등각 변형) 길이가 그 이동량의 **아조화 함수** → 내부 최대 → 상수. 그래서 T 밖의 임계값을 하나씩 T로 옮겨도 길이 불변 → 옮긴 결과도 극대.
- 인수인계서의 추정 "임계값이 모두 단위원 위"는 **존재 명제로서 확인됨**. "모든 극대 다항식이 그렇다"는 것은 아님(Remark는 |임계값| ≤ 1까지만 개요).

### 우리 계산에 쓰는 방법 (나의 추론 — 검토 필요)
- 추측 "최댓값 = L(zⁿ−1)"을 보이려면 **임계값이 모두 T 위인 다항식들 사이에서만** 최댓값을 비교하면 충분하다: 전체 최댓값을 내는 극대 다항식 중 하나가 이 부류에 있으므로 (Lemma 4 존재 + Lemma 5).
- 자유도 셈(추론): monic n차는 평행이동 z→z+b로 길이 불변 → 복소 n−1차원. 임계값 n−1개가 T 위 → 실수 n−1개(각도). 회전 p(e^{iθ}z)e^{−inθ}도 길이 불변·monic 유지 → **실수 n−2개 + 유한 개 가지(같은 임계값을 갖는 다항식이 유한 개)**. n = 3 → 1변수, n = 4 → 2변수.
  - 미확인: "임계값이 다항식을 (평행이동 빼고) 유한 개로 정한다"는 사실의 정확한 출처·조건(겹치는 임계점·겹치는 임계값 포함). 찾아서 인용해야 함.
  - 이 셈은 n = 3 원고가 "1변수 부등식"으로 줄였다는 인수인계서 기록과 맞음(원고 미독).
- MendozaLab은 계수 공간(복소 n−1차원 = 실수 2n−2) 상자 탐색 → 이 축소를 쓰면 n = 4에서 실수 6차원 → 2차원 + 가지. **계산량을 줄이는 해석적 축소가 먼저**(전수조사는 마지막 수단).
