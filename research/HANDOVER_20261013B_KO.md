## 1. 에르되시 문제 #114 — 문제와 상금

- **문제:** p(z)가 n차 monic 복소 다항식일 때, 곡선 {z : |p(z)| = 1}의 길이는 p(z) = zⁿ − 1일 때 최대인가? (EHP58)
- **비유:** 다항식으로 그린 "고무줄 고리"의 총길이가 언제 가장 긴가. 후보 정답은 꽃잎 n개짜리 대칭 모양.
- **상금 $250** (Borwein 1995 보고). 상금은 Combinatorics Foundation이 관리하며, **학술지 게재 후에만** 지급. erdosproblems.com FAQ는 지급을 약속하지 않는다. 상금은 **전체 문제** 해결 대상이다(부분 차수 결과는 대상이 아님).
- 원문 페이지: https://www.erdosproblems.com/114 , 토론 https://www.erdosproblems.com/forum/discuss/114

### 2-1. MendozaLab 철회 내용 (교훈 — 우리 설계에 그대로 반영할 것)
원저자가 인정한 결함(이슈 #4 답변, 코드 줄 번호 인용):
1. 곡선 길이를 f64 marching squares + 선형 보간으로 계산, "5% 여유"를 임의로 더함 → 길이 상한 아님.
2. 립시츠 여유를 유한차분으로 **추정**(경험 계수 0.29) → 상한 아님. n = 6에서 zⁿ − 1 근처 약 1.94 길이 단위 과소.
3. 헤시안 유한차분 — 그리고 **L은 zⁿ − 1에서 두 번 미분 가능하지 않다**(반지름 방향 |r|^(1/n) 거동).
4. "새 닫힌 꼴" L(zⁿ − 1) = 2^(1/n)·√π·Γ(1/(2n))/Γ(1/(2n)+1/2)는 고전 공식.
5. **버그:** 닫힌 구간으로 "극대점 포함 상자" 판정 → 좌표 0이 이웃 두 상자에 모두 속해 **영역의 절반(zⁿ − 1이 있는 쪽)을 평가하지 않음**, 상한 +∞로 두고 넘어감.
6. 바깥 영역(|계수| > R)은 무작위 표본 3,375개로만 덮음.
7. (이전 버전) n = 13 행: 평가 0회인데 "증명 완료" 판정(빈 벡터를 성공으로 오인) — 원저자가 포럼에서 스스로 공지.
결론(원저자): "computational census consistent with the conjecture … not a proof, not a certificate, and not independently checked for any degree 3 ≤ n ≤ 14."

## 3. 계획 (단계마다 실패 가능 — 사용자 승인: "진행 해보자")

1. **읽기 (먼저):**
   - Eremenko–Hayman 1999 원문(arXiv:0805.2295): 최대 다항식에 대한 축소(예: 임계점·임계값 조건)가 **정확히 무엇을 말하는지** 확인. 지금은 "임계값이 모두 단위원 위"라는 추정만 있음 — 원문 확인 전 사용 금지.
   - n = 3 원고(Zenodo 20318611)와 n = 4 노트(jaeseostudy): 무엇을 증명했고 무엇이 남았는지.
   - Tao 논문의 Prop 1.2(영역 축소)와 Remark 1.3.
2. **n = 3 독립 확인:** 원고가 줄인 1변수 부등식을 우리 방식(바깥 반올림 구간 연산 + 실행기와 독립된 검사기 + REFUSED/INVALID 구분)으로 확인. 원고의 해석적 단계는 별도 검토.
3. **n = 4 도전:** 축소 후 남는 저차원 족에서 엄밀한 상한. 핵심 난점(추정): (a) 곡선 길이의 엄밀한 포함(임계점을 지나는 특이 렘니스케이트 포함), (b) zⁿ − 1 근처의 비매끄러움, (c) 바깥 영역의 해석적 상한. MendozaLab 실패 7가지를 시험 항목으로 만든다(특히 "평가 0회 = 실패", 상자 경계 소속).
4. **(가능성 낮음) Tao 상수 추적으로 N₀ 명시화.**
- 공개(포럼 댓글·Zenodo·메일)는 사용자가 직접. AI 사용 공개. "최초" 주장 금지 — "찾지 못함"으로만.
