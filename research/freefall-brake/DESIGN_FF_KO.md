# 설계서 FF — 정지 출발(free-fall) 삼체 주기 궤도의 컴퓨터 보조 존재 증명

상태: **설계 초안 (사용자 검토 대기)**. 구현·실행·봉인 전. 작성 2026-10-12.
상위 방향: "수치 감사" — 수치로만 보고된 결과에 엄밀한 증명서를 발급하거나, 발급하지 못한 이유를 기록한다.

## 1. 목표
Li & Liao 2019 (New Astronomy 70, 22–26; arXiv 1805.07980)가 수치로 보고한 정지 출발 무충돌 주기 궤도(234개, 그중 231개 새것)에 대해, 구간 연산으로 **"표에 적힌 값 근처에 진짜 주기 궤도가 정확히 하나 있다"**를 증명하는 공구를 만든다.

성공 기준:
1. 교정 문제에서 정답(또는 독립 발표값)을 포함하는 결과를 낸다.
2. 첫 새 점: F1(1, 0.8, 0.8)에 대해 PASS 또는 이유가 기록된 REFUSED.

## 3. 수학 (설계 수준 — 구현 전 검토 대상)
**배치** (원 논문 2절): 질량 m1, m2, m3; r1(0)=(−0.5, 0), r2(0)=(0.5, 0), r3(0)=(x, y), 모든 속도 0, G=1.

**정지 대칭 정리 (표준 논증, 문서화 필요)**: 힘이 위치에만 의존하는 뉴턴 방정식은 시간 되돌림 대칭이다. 어떤 시각 τ>0에 세 속도가 모두 0이면 x(τ+s)=x(τ−s)이고, 따라서 x(2τ)=x(0), v(2τ)=0. 즉 주기 T=2τ인 주기 궤도. (원 논문도 "t=T/2에 모든 속도 0"을 관찰로 보고함.)

**방정식 줄이기**: 정지 출발이므로 총운동량 P=0, 각운동량 L=0이 모든 시각에 정확히 성립한다. 속도 6성분 중 3성분 g(x,y,τ) := (v1x, v1y, v2x)(τ)를 고르면, 나머지 3성분은 선형계 {P=0, L=0}에서 결정된다. 이 선형계가 해 근처에서 정칙(행렬식 구간이 0을 포함하지 않음)임을 **구간으로 확인**하면 g=0 ⇒ 6성분 모두 0. 성분 선택은 정칙성이 좋은 쪽으로 바꿀 수 있다(구현 시 결정, 기록).
미지수 3개 (x, y, τ), 방정식 3개.

**Krawczyk 판정**: X = 상자(x, y, τ), m = 중심, C ≈ (Dg(m))⁻¹ (부동소수 근사로 충분),
K(X) = m − C·g(m) + (I − C·[Dg](X))·(X − m).
K(X) ⊂ int X 이면 X 안에 g의 영점이 정확히 하나 있다(표준 정리; 출처는 구현 전에 원문 확인 후 인용).
- g(m): 점 초기조건 (x_m, y_m)에서 시각 τ_m까지 엄밀 적분한 속도 구간.
- [Dg](X): ∂g/∂(x,y) = 변분 방정식의 해(초기조건 상자 위 전체에서 포함), ∂g/∂τ = 가속도 f(x(τ))의 해당 성분(시각 구간 위에서 포함).

**충돌**: 원 논문은 최소 거리 > 10^-6인 궤도만 실었다. 정칙화는 구현하지 않는다. 엄밀 적분이 근접 조우에서 실패하면 그 궤도는 REFUSED(사유: 근접 조우)로 기록하고 넘어간다.

## 4. 구성 요소 (각각 따로 시험 가능)
| 단위 | 하는 일 | 의존 |
|---|---|---|
| `ff_system` | 질량·(x,y)로 초기 상태 생성, 보존량 P, L, 에너지 계산 | `taylor_step.make_nbody` |
| `ff_flow` | 초기조건 상자 → 시각 τ 구간에서 상태 상자 + Dφ 상자 | `lohner_step` (확장 방법은 5절 결정) |
| `ff_krawczyk` | g, [Dg]로 K(X) 계산, 포함 판정, 결과 JSON | `dyad` |
| `ff_check` (독립) | 실행기 결과 JSON을 읽어 Krawczyk 포함을 **실행기 코드 없이** 정확한 Fraction으로 재확인 + 점 궤도를 별도 방법(mpmath 고정밀, 비엄밀)으로 재계산해 일치 확인 | 표준 라이브러리 + mpmath |
| `ff_prescan` | 후보 궤도의 최소 거리·민감도를 부동소수(scipy DOP853)로 미리 측정 (비엄밀, 후보 선별용) | scipy |

판정 기록: PASS / REFUSED(사유) / INVALID(포함 실패가 아니라 "해가 없다"는 증거가 있을 때만) / UNRESOLVED. REFUSED와 INVALID를 섞지 않는다.

## 5. 결정할 것 (사용자·구현 전)
- **D1. Dφ 계산 방식**: (가) 상태+변분(12+12×2=36차원)을 하나의 계로 Lohner 적분 — 단순, 느림. (나) 걸음별 `[J]` 포함 행렬을 구간 곱으로 누적 — 빠르나 감싸기 과대평가 큼. **추천: (가)**, 미지수가 2개(x, y)라 변분 열이 2개뿐이다. → **C1에서 (나)로 실행함**(봉인 코드의 diag["J"] 재사용; `C1_RESULT_KO.md` 4절). 긴 궤도에서 과대평가가 크면 (가) 재검토.
- **D2. CAPD를 독립 검사기로 쓸지**: 쓰면 독립성이 커지나 C++ 외부 라이브러리 설치·학습 비용. **추천: 이번엔 쓰지 않고, 첫 PASS 뒤 재검토.**
- **D3. 좌표**: 원 논문 좌표 그대로(추천, 비교가 쉬움). 무게중심 좌표는 7절 실험으로 미룸.

## 6. 교정 → 첫 새 점 (순서, 각 단계는 별도 봉인 계획으로 실행)
| 단계 | 문제 | 비교 대상 | 증거 성격 |
|---|---|---|---|
| C1a | 1차원 조화진동자 x''=−x, 정지 출발: 다시 정지하는 시각 τ | 정확한 답 π | 정답 있음 — **PASS** |
| C1b | 케플러 μ=1, (3/2,0)·속도 (0,v0) → 근점 (−1/2,0): 미지수 v0, τ (초기조건 미분 경로 시험용으로 추가) | 1/√3, π | 정답 있음 — **PASS** |

## 7. 문서만: 무게중심 좌표 실험 (오차 줄이기 목표)
근거: `../pythagorean-3body/analysis_width/WIDTH_ANALYSIS_KO.md` 3·4절 — t=61 상자가 운동량·무게중심(참값 0) 방향으로도 거의 전체 폭만큼 부풀어 있고, 후반부 과대평가가 약 10^6배로 추정됨.
실험안: 같은 피타고라스 문제를 무게중심 좌표(8차원)로 같은 128비트 설정에서 다시 돌려 t=61 폭과 도달 시각을 비교. 서버 몇 시간 예상(추정). **별도 봉인 계획·승인 후에만.**

## 8. 위험
- 원 논문 표가 10자리라 초기 상자가 10^-10 정도. Krawczyk 수축이 안 되면 고정밀 뉴턴으로 중심을 먼저 다듬어야 한다(비엄밀 단계, 결과는 Krawczyk가 판정).
- 근접 조우가 가까운 궤도는 정칙화 없이 실패할 수 있다.
- 궤도 하나 비용 미측정. 피타고라스(t=61, 2.2시간 C++)보다 짧은 T이지만 변분 포함으로 차원이 3배.
- 경쟁: 단일 궤도 Krawczyk 증명을 한 개인 저장소 1건(Majumder, 2026, 비심사)과 CAPD 그룹. 정지 출발 목록의 엄밀 검증 선행 연구는 찾지 못함(부재 증명 아님).
- 정지 대칭 정리와 Krawczyk 정리는 표준이나, 구현 전에 원 출처를 확인해 인용한다.
