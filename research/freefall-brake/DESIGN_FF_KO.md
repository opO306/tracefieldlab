# 설계서 FF — 정지 출발(free-fall) 삼체 주기 궤도의 컴퓨터 보조 존재 증명

상태: **설계 초안 (사용자 검토 대기)**. 구현·실행·봉인 전. 작성 2026-10-12.
상위 방향: "수치 감사" — 수치로만 보고된 결과에 엄밀한 증명서를 발급하거나, 발급하지 못한 이유를 기록한다.

## 1. 목표
Li & Liao 2019 (New Astronomy 70, 22–26; arXiv 1805.07980)가 수치로 보고한 정지 출발 무충돌 주기 궤도(234개, 그중 231개 새것)에 대해, 구간 연산으로 **"표에 적힌 값 근처에 진짜 주기 궤도가 정확히 하나 있다"**를 증명하는 공구를 만든다.

성공 기준:
1. 교정 문제에서 정답(또는 독립 발표값)을 포함하는 결과를 낸다.
2. 첫 새 점: F1(1, 0.8, 0.8)에 대해 PASS 또는 이유가 기록된 REFUSED.

## 3. 수학 (설계 수준 — 구현 전 검토 대상)
**배치** (원 논문 2절): 질량 m1, m2, m3; r1(0)=(−0.5, 0), r2(0)=(0.5, 0), r3(0)=(x, y), 모든 속도 0, G=1.

**정지 대칭 정리 (표준 논증, 문서화 필요)**: 힘이 위치에만 의존하는 뉴턴 방정식은 시간 되돌림 대칭이다. 어떤 시각 τ>0에 세 속도가 모두 0이면 x(τ+s)=x(τ−s)이고, 따라서 x(2τ)=x(0), v(2τ)=0. 즉 주기 T=2τ인 주기 궤도. (원 논문도 "t=T/2에 모든 속도 0"을 관찰로 보고함.)

**방정식 줄이기**: 정지 출발이므로 총운동량 P=0, 각운동량 L=0이 모든 시각에 정확히 성립한다. 속도 6성분 중 3성분 g(x,y,τ) := (v1x, v1y, v2x)(τ)를 고르면, 나머지 3성분은 선형계 {P=0, L=0}에서 결정된다. 이 선형계가 해 근처에서 정칙(행렬식 구간이 0을 포함하지 않음)임을 **구간으로 확인**하면 g=0 ⇒ 6성분 모두 0. 성분 선택은 정칙성이 좋은 쪽으로 바꿀 수 있다(구현 시 결정, 기록).
미지수 3개 (x, y, τ), 방정식 3개.

**Krawczyk 판정**: X = 상자(x, y, τ), m = 중심, C ≈ (Dg(m))⁻¹ (부동소수 근사로 충분),
K(X) = m − C·g(m) + (I − C·[Dg](X))·(X − m).
K(X) ⊂ int X 이면 X 안에 g의 영점이 정확히 하나 있다(표준 정리; 출처는 구현 전에 원문 확인 후 인용).
- g(m): 점 초기조건 (x_m, y_m)에서 시각 τ_m까지 엄밀 적분한 속도 구간.
- [Dg](X): ∂g/∂(x,y) = 변분 방정식의 해(초기조건 상자 위 전체에서 포함), ∂g/∂τ = 가속도 f(x(τ))의 해당 성분(시각 구간 위에서 포함).

**충돌**: 원 논문은 최소 거리 > 10^-6인 궤도만 실었다. 정칙화는 구현하지 않는다. 엄밀 적분이 근접 조우에서 실패하면 그 궤도는 REFUSED(사유: 근접 조우)로 기록하고 넘어간다.

## 8. 위험
- 원 논문 표가 10자리라 초기 상자가 10^-10 정도. Krawczyk 수축이 안 되면 고정밀 뉴턴으로 중심을 먼저 다듬어야 한다(비엄밀 단계, 결과는 Krawczyk가 판정).
- 근접 조우가 가까운 궤도는 정칙화 없이 실패할 수 있다.
- 궤도 하나 비용 미측정. 피타고라스(t=61, 2.2시간 C++)보다 짧은 T이지만 변분 포함으로 차원이 3배.
- 경쟁: 단일 궤도 Krawczyk 증명을 한 개인 저장소 1건(Majumder, 2026, 비심사)과 CAPD 그룹. 정지 출발 목록의 엄밀 검증 선행 연구는 찾지 못함(부재 증명 아님).
- 정지 대칭 정리와 Krawczyk 정리는 표준이나, 구현 전에 원 출처를 확인해 인용한다.

## 10. 점선 사격(다중 사격) 설계 — 2026-10-13 추가 (사용자 결정: "점선 사격으로 가자")

**왜:** C2 실행(`server_out/`, ledger)에서 세 궤도 모두 REFUSED. N1은 g(m) 폭 10^-27·중심 정확·보존 검사 통과인데 [Dg] 폭이 10^4.7(중간값 ~10^2) — 약 1,500걸음의 [J] 구간 곱이 과대평가. C2·C3은 초기 상자가 근접 조우에서 충돌 배치까지 번짐. 둘 다 "긴 구간을 한 번에 운반"이 원인이다.

**구조:** 궤도 위에 중간 역 k−1개(시각 t_1<…<t_{k−1}, 이진 분수, 고정)를 찍는다.
- 미지수 u = (p, z_1, …, z_{k−1}, τ): p = 별3 위치 (x, y), z_i ∈ R^12 = 시각 t_i의 상태. 개수 2 + 12(k−1) + 1.
- 방정식: φ_{t_1}(x0(p)) − z_1 = 0, φ_{t_i − t_{i−1}}(z_{i−1}) − z_i = 0 (i = 2..k−1), v_E(φ_{τ − t_{k−1}}(z_{k−1})) = 0. 개수 12(k−1) + 3 (정사각).
- 해가 있으면 이음매가 정확히 이어진 하나의 궤도이므로 단일 사격의 해와 같다(표준 동치).
- [Dg]는 블록 이중대각: 구간마다 [Dφ](구간 시작 상자) 와 −I. 각 구간 미분은 짧은 구간의 [J] 곱이라 과대평가가 작다(기대, 미측정).

**중심값:** 중간 역 중심 z_i는 부동소수가 아니라 **우리 엄밀 적분기로 m_p에서 출발한 점 적분**의 상자 중간값(폭 ~10^-27)으로 잡는다 — 부동소수 다듬기의 10^-13 한계를 피한다.

**오차를 양분으로 (재시도 규칙):** REFUSED이면 Krawczyk 결과 K(참 해가 X 안에 있다면 K 안에 있음)의 중간값으로 중심을 옮기고 반지름을 K 반폭의 2배(최대 8배 증가)로 잡아 최대 2번 재시도(Rump식 ε-팽창). 모든 시도를 기록한다. 판정은 여전히 Krawczyk 포함만.

**역 위치:** 사전 조사(비엄밀)의 근접도 가중 ∫ r_min^{-3/2} dt를 k등분하는 시각을 2^-16 단위로 내림. 근접 조우가 한 구간 안에 갇히도록.

**병렬(릴레이):** 중심이 정해지면 구간별 점 적분·상자 적분이 서로 독립 → 리눅스 서버에서 fork 프로세스로 구간 병렬. 노트북(Windows)은 순차.

**실패 기록(우리 방식으로 실패):** 구간별로 [J] 곱 폭, 상자 폭, singular 여부, 걸음 수를 남긴다 — 어느 구간이 막았는지 보이게.

**하지 않는 것:** 정칙화, 봉인 파일 수정, A안(Lohner식 미분)은 구간 안 과대평가가 남을 때의 다음 후보로만 기록.

## 11. 구간 안 미분을 Lohner식으로 (2026-10-13, 사용자 결정 "작업 계속") — MS_RESULT_KO.md 근거
- 기존(product): M_k = [J_k]·M_{k−1}. 점선 사격 N1에서 구간당 ~200걸음의 이 곱이 [Dg] 폭 최대 0.42를 만들어 Krawczyk 수축 실패.
- 새(lohner): 미분 행렬 집합을 V ∈ A + B·R (A 점 행렬, B 상태 적분의 Lohner 틀, R 구간 행렬)로 들고 간다. 한 걸음: A' = mid([J])·A 를 이진 분수로 내림, R' = [B'⁻¹]·( ([J]·B)·R + (mid([J])·A − A') + ([J] − mid([J]))·A ). B' = 새 상태의 틀(`state_new.B`), [B'⁻¹] = diag["Binv"](정확한 역행렬)의 바깥 반올림.
- 근거: 참 J ∈ [J], V ∈ A + B R 이면 J V = A' + B' r', r' = B'⁻¹(J B r + (J−mid J)A + (mid J·A − A')) ∈ R' (구간 포함 단조성, lohner_step 모듈 설명 (6)과 같은 논증). 초기 A = S(점), R = 0.
- 끝에서 M = A + [B]·R (구간). 마지막 미소 걸음은 기존대로 W·M.
- 기존 product 경로는 그대로 두고 선택 인자(deriv="lohner")로 켠다.
- **측정 결과(2026-10-13): 채택하지 않음.** 케플러 상자 출발(r = 2^-30, T = 3)에서 미분 폭 product 10^-4.49, lohner 10^-4.02 — 개선 없음(약간 나쁨). r = 2^-20이면 둘 다 약 1000배 넓어짐 → 미분 폭은 감싸기 누적이 아니라 **상자 반지름 r에 비례**(상자 위 미분의 실제 변화 + 구간 의존성). 코드는 되돌렸다.
- **새 해석:** K 반폭 ≈ |C|·폭(g(m))/2 + |C|·κ·r² (κ = 미분 폭/r) → K/X ∝ r. N1은 중심이 매우 정확(|mid K − m| ≈ 10^-27)한데 r = 2^-30을 썼고, 재시도가 r을 키웠다(역방향). 최적 r ≈ √(폭(g)/κ) — N1 추정 10^-17~10^-15(추론). 다음: r을 2^-50 수준으로 줄여 단일·점선 사격 재실행.
