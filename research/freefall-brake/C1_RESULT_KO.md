## 2. 실행 중 발견 (기록)
- **C1b가 처음 h_max=1/16에서 REFUSED.** 원인 확인: 고정 보폭이라 테일러 나머지를 통제하지 않아 점 적분 g(m) 폭이 10^-8.5까지 커짐(정상 10^-35 근처). 측정: 1/32 PASS(K 10^-17, 20초), 1/64 PASS(10^-21, 41초), 1/128 PASS(85초). 판정 논리는 그대로이고 보폭만 바꿈.
  → **삼체(C2 이후)에는 고정 보폭이 아니라 나머지 기준 보폭 제어가 필요**(R4의 `step_size(tol, m)` 방식).
- [Dg] 폭이 C1b에서 10^-8.6 정도로, 상자 폭(10^-11.7)보다 크다. 걸음별 [J] 곱의 과대평가로 추정(미분석). 이번 판정에는 문제없었으나 긴 궤도에서는 D1 (가) 방식 재검토 근거가 될 수 있음.

## 3. 정리의 근거 (출처 확인 범위를 그대로 적음)
- **존재**: Schichl & Neumaier, SIAM J. Numer. Anal. 42(1), 383–408 (2004), DOI 10.1137/S0036142902418898, Theorem 2.2 (Kahan): 어떤 행렬 C에 대해 Krawczyk 연산자 K(z, x) ⊆ x 이면 x 안에 영점이 있다. 원문 PDF에서 직접 읽음. 이 정리는 기울기(slope) 포함 행렬로 진술되며, 상자 위 미분의 구간 포함 [Dg](X)는 평균값 정리에 의해 기울기 포함이 된다(우리 사용 형태).
- **유일성**: 같은 정리의 유일성 진술은 K(x, x) ⊆ int(x) 꼴이라 우리 계산 형태와 정확히 같지 않다. Bozóki–Lee–Rónyai (arXiv 1308.5164) 3.2절은 C = DF(x)^-1 (정확한 역행렬)일 때 "K ⊂ int ⇒ 유일한 영점"을 진술한다(원문 읽음). 근사 C에 대한 일반 진술(Neumaier 1990 책 5장, Rump 1983)은 **원문을 읽지 못함**.
  - 그래서 유일성은 다음 **초등적 논증**으로 따로 확인했다: 정확한 유리수로 계산한 ‖I − C·[Dg]‖∞ 상한이 C1a 2.5×10^-24, C1b 3.2×10^-9 (< 1). 그러면 [Dg] 안의 모든 행렬 A에 대해 C·A = I − E (‖E‖<1)가 가역이므로 A도 가역이다. X가 볼록이므로 서로 다른 두 영점 a, b가 있으면 0 = g(a) − g(b) = Ā(a − b), Ā = ∫₀¹ Dg(b + s(a−b)) ds ∈ [Dg] (구간 행렬은 볼록) → Ā 가역이므로 a = b. 최종 검토 뒤 이 계산을 `ff_check`에 넣었다(결과 JSON의 `independent_check.unique`, `norm_I_minus_CDg`). 두 결과 모두 unique=True.
- 출처: [Schichl & Neumaier 2004 PDF](https://www.mat.univie.ac.at/~herman/papers/041889.pdf), [Bozóki–Lee–Rónyai, arXiv 1308.5164](https://arxiv.org/pdf/1308.5164).

## 4. 설계서와 다른 점
1. D1: 흐름 미분을 (나) 걸음별 [J] 구간 곱으로 계산(봉인 코드의 diag["J"] 재사용, 새 수학 없음).
2. C1을 C1a(조화진동자)·C1b(케플러)로 나눔 — 조화진동자는 초기조건 미분 경로를 시험하지 못하므로.

## 5. 아직 아닌 것 / 다음
- 삼체 미적용. C2(Yasko–Orlov F2(1,1,1))는 별도 계획: 나머지 기준 보폭 제어, 운동량·각운동량으로 줄인 방정식의 정칙성 구간 확인, `ff_prescan`, 유일성 노름 검사의 `ff_check` 편입.
- 정지 대칭 정리(시간 되돌림) 출처 확인은 C2 계획에서.

## 6. 최종 검토 반영 (새 검토자 1회, Critical 없음)
- 검사기 설명이 과장됨 → 고침: X가 기록된 m ± r와 맞는지 확인 추가(상자 넓히기 수정 → FAIL), 못 잡는 수정(g(m)·[Dg] 좁히기)을 문서에 명시.
- 입력에 따라 크래시 → REFUSED로: 특이/비유한 [Dg] 중간값, 이진 분수가 아닌 시작값(1/3 등), 0 이하를 포함하는 시각 상자.
- 유일성이 코드로 판정되지 않음 → `ff_check`에 ‖I − C·[Dg]‖∞ 정확 계산 추가. `ff_krawczyk` 설명은 "존재"로 낮춤.
- 미뤄 둔 사소한 것: 미소 걸음 반감 경로 미시험, REFUSED 레코드를 검사기에 넣으면 KeyError, 차원 불일치 검사 없음.
